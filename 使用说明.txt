暖屿找房演示说明

1. 启动项目
双击：
启动演示.bat

系统会自动：
- 启动后端服务
- 启动前端页面
- 自动打开浏览器

默认访问地址：
http://127.0.0.1:5173

2. 关闭项目
演示结束后，双击：
关闭演示.bat

3. 测试账号
普通用户：
user1 / password

经纪人：
agent1 / password

管理员：
admin / password

4. 功能说明
- 普通用户可浏览房源、查看地图、收藏、预约、评论、咨询
- 经纪人可发布和管理房源、处理预约、回复咨询
- 管理员可审核房源、管理用户、管理评论、处理消息

5. 说明
- 首次启动时，如页面未立即显示，可等待几秒后刷新浏览器
- 如需重新演示，建议先点击“关闭演示.bat”，再重新启动
