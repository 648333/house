## 第 2 页 课题背景与研究目标
### 页面标题
课题背景与研究目标

### 页面内容
- 传统房屋交易存在信息分散、流程繁琐、效率低的问题
- 目标：构建一个支持多角色协同的房屋交易平台
- 实现房源发布、检索、预约、咨询、管理等核心流程

### 讲解要点
本课题来源于现实中的房屋交易场景。传统模式下，房源信息分散、用户沟通成本高、预约和后续管理缺乏统一平台支持。因此，我希望实现一个前后端分离的房屋交易平台，围绕普通用户、经纪人和管理员三类角色，打通从浏览房源到预约、咨询再到后台管理的完整业务链路。

## 第 3 页 技术路线与系统架构
### 页面标题
技术路线与系统架构

### 页面内容
- 前端：Vue3 + Vite + Element Plus
- 后端：Spring Boot + Spring Security + JWT + JPA
- 数据库：MySQL
- 辅助技术：ECharts、Leaflet、3D 模型展示

### 讲解要点
系统采用前后端分离架构。前端负责页面展示和交互，后端负责接口、权限和业务逻辑处理，数据库用于持久化存储业务数据。认证方式采用 Spring Security 加 JWT，实现无状态登录与角色权限控制。为了增强展示效果，我还加入了统计图表、地图找房和 3D 看房等扩展功能。

## 第 4 页 功能模块设计
### 页面标题
系统功能模块

### 页面内容
- 用户模块：注册、登录、个人信息管理
- 房源模块：发布、编辑、审核、查询、筛选
- 业务模块：预约看房、在线咨询、评论、工单
- 管理模块：经纪人工作台、管理员后台、统计分析
- 扩展模块：推荐、地图找房、3D 看房、软装设计

### 讲解要点
系统按角色和业务流程划分为多个模块。普通用户可以完成找房、收藏、预约和咨询；经纪人可以发布和管理自己的房源，并处理预约和工单；管理员可以审核房源、管理用户并查看统计信息。在基础功能之外，我还实现了个性化推荐、地图找房和 3D 展示等扩展模块，提升系统完整度和展示亮点。
