# 暖寓找房系统功能说明

## 1. 系统概述

“暖寓找房”是一个面向房产交易与找房服务场景的综合平台，采用前后端分离架构实现。系统不仅完成了基础的用户注册、登录、房源浏览与发布，还进一步实现了找房推荐、地图找房、预约看房、在线咨询、意向金支付、需求匹配、客服工单、管理后台、经纪人工作台、3D 看房与软装工作室等扩展能力。

从当前项目代码来看，这个系统已经不再是一个简单的“房源展示网站”，而是一个覆盖“用户找房、经纪人运营、管理员治理、推荐训练支撑”的多角色房产服务平台。

## 2. 系统目标

本系统主要解决以下问题：

- 为普通用户提供从搜索房源、浏览详情、在线咨询、预约看房到支付意向金的一站式找房流程。
- 为经纪人提供房源发布、预约处理、排班管理、工单处理等日常运营工具。
- 为管理员提供用户管理、房源审核、评论治理、站内消息处理、推荐训练数据导出与预测结果导入能力。
- 为推荐系统与后续数据分析预留训练、导入、统计和交互埋点基础。
- 通过地图、收藏、对比、需求匹配、3D 看房和软装编辑等功能提升找房效率和展示效果。

## 3. 角色与权限设计

系统当前已实现三类主要角色：

### 3.1 普通用户（USER）

普通用户可以：

- 注册、登录、找回密码、重置密码。
- 浏览首页、房源列表、房源详情、地图找房页面。
- 收藏房源、最近浏览、房源对比。
- 发布找房需求并查看需求匹配结果。
- 查看个性化推荐房源。
- 在线咨询房源顾问。
- 发起预约看房并支付意向金。
- 订阅价格提醒。
- 发表评论。
- 在个人中心查看预约记录、预约进度、咨询消息、客服工单、收藏房源、最近浏览和找房需求。

### 3.2 经纪人（AGENT）

经纪人可以：

- 发布和编辑自己的房源。
- 查看自己发布的房源并更新成交状态。
- 查看和处理用户预约。
- 配置可预约的排班时段。
- 查看并处理客服工单。
- 进入经纪人工作台进行运营管理。

### 3.3 管理员（ADMIN）

管理员可以：

- 查看后台统计信息。
- 审核房源，执行通过或驳回。
- 查看并启用/禁用用户。
- 管理评论内容。
- 处理站内消息会话。
- 导出推荐训练数据集。
- 导入离线模型生成的推荐预测结果。

## 5. 核心业务流程说明

## 5.1 用户找房主流程

1. 用户注册并登录系统。
2. 在首页、房源列表或地图页搜索房源。
3. 通过标签、类型、收藏、排序等方式筛选目标房源。
4. 进入房源详情页查看信息、预算、评论、虚拟看房内容。
5. 用户可选择收藏、对比、在线咨询、预约看房。
6. 预约时可结合经纪人排班选择时间，并支付意向金。
7. 后续在个人中心查看预约进度、消息和工单处理情况。

## 5.2 经纪人运营流程

1. 经纪人登录工作台。
2. 发布或编辑房源，等待管理员审核。
3. 审核通过后，房源进入前台展示。
4. 经纪人配置看房排班。
5. 经纪人处理用户预约申请。
6. 经纪人处理客服工单和用户问题。
7. 房源成交后，可更新房源状态。

## 5.3 管理员治理流程

1. 管理员进入后台查看统计总览。
2. 审核新提交的房源。
3. 管理用户状态。
4. 审核或删除评论。
5. 查看站内消息并进行管理沟通。
6. 导出推荐训练数据。
7. 导入离线模型预测结果，增强推荐能力。

- 数据权限、审计日志、异常处理和接口校验还可以做得更严谨。
