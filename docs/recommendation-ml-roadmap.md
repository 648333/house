# 房产平台推荐系统与机器学习落地路线

## 优先级

1. 修复完整性问题
2. 升级为混合推荐
3. 完成交互埋点与训练数据底座
4. 上线第一版机器学习排序模型
5. 完善 3D / 全景看房
6. 做模型效果评估与 A/B
7. 再升级召回与深度模型

## 当前系统现状

- 后端已经有规则推荐服务，适合做冷启动和解释性推荐。
- 平台已经具备收藏、预约、评论、咨询、对比、看房流程，适合沉淀用户行为特征。
- 当前最缺的是统一的交互日志、训练样本生产流程、离线训练脚本和在线推理接口。

## 第 4 项完整流程

### 1. 定义目标

第一版机器学习不要直接预测成交，先预测更稳定的中间目标：

- 点击详情
- 收藏
- 发起咨询
- 发起预约

推荐排序分数可以先定义为加权目标：

- 浏览详情 = 1
- 打开 3D / 全景 = 2
- 收藏 = 3
- 对比 = 2.5
- 咨询 = 3.2
- 预约 = 4
- 评论 = 3.5

### 2. 采集数据

平台要持续记录以下字段：

- `user_id`
- `property_id`
- `action_type`
- `weight`
- `source`
- `metadata`
- `created_at`

训练时再补充用户特征、房源特征和上下文特征。

### 3. 构造训练样本

推荐排序样本格式建议如下：

- 标签 `label`
- 用户特征 `user_features`
- 房源特征 `item_features`
- 上下文特征 `context_features`

可用特征示例：

- 用户近 30 天浏览次数
- 用户近 30 天收藏次数
- 用户偏好区域
- 用户偏好户型
- 用户预算区间
- 房源价格
- 房源面积
- 房源类型
- 房源标签
- 房源发布时间
- 房源是否有 3D / 全景
- 房源是否在通勤圈内

### 4. 训练方案

第一版推荐训练建议：

- 模型：LightGBM Ranker 或 XGBoost Ranker
- 训练粒度：每天离线训练一次
- 训练窗口：最近 30 到 90 天
- 数据切分：按时间切分训练集、验证集、测试集

原因：

- 对结构化特征非常友好
- 训练速度快
- 可解释性比深度模型更强
- 更适合你现在的数据规模

### 5. 评估指标

离线评估至少看这些：

- Precision@K
- Recall@K
- NDCG@K
- MAP
- MRR

业务指标建议看：

- 推荐位点击率 CTR
- 收藏率
- 咨询率
- 预约率

### 6. 部署方式

推荐分两层：

1. 召回层
   先用规则召回一批候选房源
2. 精排层
   用 LightGBM / XGBoost 对候选集打分排序

在线服务建议：

- Java 主服务继续负责接口聚合
- Python 训练服务离线产出模型文件
- Java 读取模型分数结果或调用 Python 推理服务

更稳的第一版做法：

- Python 离线生成每个用户的推荐结果表
- Java 直接读取推荐结果表返回给前端

### 7. 上线策略

先走灰度，不要全量替换现有规则推荐。

- `ranker_version=rule_v1`
- `ranker_version=hybrid_v2`
- `ranker_version=lgbm_v3`

先对小流量用户灰度，再比较：

- 点击率
- 收藏率
- 咨询率
- 预约率

### 8. 回滚策略

必须保留规则推荐兜底：

- 模型服务失败
- 特征缺失
- 新用户冷启动
- 数据延迟

回滚时直接退回 `hybrid_v2`。

## 混合推荐建议

上线机器学习前，先做一版混合推荐：

- 规则得分
- 行为得分
- 新房源加权
- 价格预算匹配
- 户型匹配
- 区域匹配
- 标签匹配
- 3D / 全景加权

最终分数可用：

`final_score = rule_score * 0.45 + behavior_score * 0.35 + model_score * 0.20`

在没有模型时：

`final_score = rule_score * 0.6 + behavior_score * 0.4`

## 3D 功能路线

### 第一阶段

- 支持 `panoramaUrl`
- 支持多场景 `panoramaImages`
- 支持 `floorPlanUrl`
- 支持 `model3dUrl`

### 第二阶段

- 对接 360 全景查看器
- 支持房间切换
- 支持热点标注
- 支持打开楼层平面图

### 第三阶段

- 对接 `three.js` 或 `model-viewer`
- 加载 `glb/gltf`
- 支持旋转、缩放、热点说明
- 统计 3D 场景停留时长
